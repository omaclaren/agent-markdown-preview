What happens in the demo

The imports and Lorenz function are loaded before filming. The example code includes that setup.

  1. Pi integrates a Lorenz trajectory, stores it as a and plots the attractor.
  2. The operator sends b = odeint(lorenz, [1.0001, 1, 1], t) with !agent-repl-py, from Pi’s shell mode.
  3. Claude Code reuses a and b to plot how their separation grows. Both plots appear inline on the REPL page.

Open a preview

From the project directory where you are working with an agent:

npm install -g agent-markdown-preview
agent-markdown-preview --repl

Leave off --repl for responses only. The REPL page is optional and reads existing sessions from agent-repl, pi-repl or Pi Studio; it does not run code.

Requires Node.js 22+ and Pandoc. Use Node.js 22.13+ for OpenCode sessions. See the installation notes for platform and rendering dependencies.
