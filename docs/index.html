Browser previews for coding agents

agent-markdown-preview renders responses from Claude Code, Codex, Pi and OpenCode in a browser, with equations, syntax highlighting and diagrams. It reads the agents’ existing session histories, so no agent configuration is needed.

Open video Python example Shared REPL setup

What happens in the demo

The imports and Lorenz function are loaded before filming. The Python example includes that setup.

  1. Pi integrates a Lorenz trajectory, stores it as a and plots the attractor.
  2. The operator sends b = odeint(lorenz, [1.0001, 1, 1], t) with !agent-repl-py, from Pi’s shell mode.
  3. Claude Code uses a and b to plot how their separation grows. Both plots appear inline on the REPL page.

Installation

You need Node.js 22 or later and Pandoc. OpenCode sessions require Node.js 22.13 or later.

npm install -g agent-markdown-preview

From the project directory where you are working with an agent, run:

agent-markdown-preview

This opens an index of the project’s recent agent sessions. Open a session to read its responses as they are completed. Add --live to follow recorded prompts, tool calls and results during a turn.

For a local Markdown, LaTeX, code or diff file, pass its path to the command.

Shared REPL code and plots

To add the REPL page shown in the video, run:

agent-markdown-preview --repl

The page reads recorded submissions from agent-repl, pi-repl or Pi Studio sessions. It shows the submitted code and output, including saved plots; it does not run code.

Keep live preview links private, since anyone with a link can read the content it exposes. The redactions in the video do not apply to live previews. See the security notes and full documentation for details.
